# Booking & BL Workflow Practice

This folder documents a practical Booking and Bill of Lading (BL) workflow for a shipping/logistics operation.

## Purpose
The goal is to define the operational flow from booking request to cargo release, with clear statuses, stakeholders, and process rules.

## Scope
This workflow covers:
- booking creation
- validation and approval
- carrier confirmation
- cargo receipt and loading
- BL issuance and amendment
- cargo release and closure

## Core participants
- Shipper
- Freight forwarder / operations team
- Carrier / shipping line
- Customs broker
- Consignee
- Internal support / documentation team

## Output
The deliverables in this folder include:
- workflow description
- status mapping
- user stories
- sample data model
- business process diagram
- SQL schema
- simple app flow
- mock UI workflow
- working prototype app
